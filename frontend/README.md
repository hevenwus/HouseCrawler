
# HouseCrawler 前端界面

一个精美奢华风格的房产数据展示页面，用于展示从多个平台爬取的房产信息。

## 设计特点

- **奢华黑金风格**：采用金色为主色调，深色背景，营造高端质感
- **精美动画效果**：页面加载动画、数字滚动、卡片悬浮效果
- **响应式设计**：适配各种屏幕尺寸
- **丰富交互**：数据源筛选、类型筛选、搜索功能、网格/列表视图切换

## 技术栈

- HTML5
- CSS3 (变量、动画、Grid、Flexbox)
- Vanilla JavaScript (ES6+)
- 外部字体：Playfair Display (展示字体)、Noto Sans SC (中文字体)

## 文件结构

```
frontend/
```

## 使用方法

### 直接打开

直接在浏览器中打开 `index.html` 文件即可查看效果。

### 使用本地服务器

推荐使用本地服务器以获得最佳体验：

```bash
# 使用 Python
python3 -m http.server 8000

# 或使用 Node.js (http-server)
npx http-server -p 8000
```

然后在浏览器中访问 `http://localhost:8000`

## 功能说明

### 导航筛选
- 点击顶部导航按钮可以按数据源筛选（全部/贝壳/豆瓣/巴乐兔）

### 数据统计
- 页面顶部展示四个统计数据：总房源、今日更新、平均价格、数据来源
- 数字带有滚动动画效果

### 筛选控制
- **类型筛选**：全部/租房/二手房/成交记录
- **区域筛选**：全部/徐汇/肥西/上海
- **搜索框**：支持按标题和地址搜索

### 视图切换
- 网格视图：卡片式布局，适合浏览
- 列表视图：单列布局，信息更紧凑

### 房源卡片
- 显示房源图片、标题、地址、户型、面积、楼层、价格、发布时间
- 鼠标悬停时有缩放和阴影效果
- 显示来源标签和特色标签

## 自定义数据

要使用真实的爬虫数据，修改 `app.js` 中的 `mockProperties` 数组，替换为你的真实数据格式。
